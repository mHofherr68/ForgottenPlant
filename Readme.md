Readme ForgottenPlant Hofherr ABS 22.04.2026



Spielinformation:



Github Repo: https://github.com/mHofherr68/ForgottenPlant





Das Spiel wird in der Scene SC\_MainMenu gestartet.



Im MainMenu hat man die Auswahl zwischen:

Neues Spiel	-> Startet das Game

Optionen	-> Öffnet die Spiel Optionen

Spiel Laden	-> Nicht implementiert

Beenden		-> Spiel komplett Beenden



Bei Den Optionen befinden sich Einstellungen für:

Grafik	->

&#x09;Auflösung	-> Im Code Aktiv, aber nicht im Unity Editor. Erst nach dem Build Funktional.

&#x09;Vollbild	-> siehe oben.

Audio	->

&#x09;Haupt Vol	-> Regelt die Haupt Lautstärke

&#x09;SFX Vol		-> Regelt die SFX Lautstärke

&#x09;Sprach Vol	-> Regelt die Sprach Lautstärke

&#x09;Musik Vol	-> Regelt die Musik Lautstärke

Maus	->

&#x09;Empfindlichkeit	-> Maus x-y Empfindlichkeit

&#x09;Maus Invertieren-> Maus Y invertieren

Diverses->

&#x09;Schweregrad	-> Schweregrad des Spiels

&#x09;Track		-> Wählt einen von 4 Hintergrund Loops aus

Button Speichern	-> Übernimmt die gemachten Einstellungen ins Persistente Live System

&#x09;		   und Speichert diese in einer .JSON Datei. Genaueres Siehe GDD.

Button Verwerfen	-> Stellt die zuvor gültigen Einstellungen wieder her.





Steuerung:

Maus 			→ Bewegungsrichtung / Zielen

L MT			→ Schießen

R MT			→ Waffe „PotatoMotar“, Zoomen

Mausrad		→ Waffen Auswahl

WASD		→ Bewegung

WSAD + Shift(L)	→ Schleichen

Q			→ Nach inks beugen (umsehen)

E			→ Nach rechts beugen (umsehen)

Space 		→ Springen

ESC 			→ Pause Menü / GamePlay optionen



Verwendung von ChatGPT

Zur Unterstützung bei der Entwicklung wurde ChatGPT verwendet. Es wurden keine weiteren KI Systeme genuzt.

Die Unterstützung umfasste insbesondere Hilfestellungen bei Codeanalyse, Fehlersuche, Strukturierung und Formulierung.

Die fachliche Entscheidung, Logische Zusammenhänge, Auswahl, Anpassung der Scripte sowie praktische Umsetzung 

und Überprüfung der Inhalte erfolgte eigenständig.
